# Code Copyright Deposit Guide - Ivy Wolf Art software

*Protects the software itself. File at copyright.gov. Per U.S. Copyright Office Circular 61.
Not legal advice.*

## What to deposit
- The **first 25 pages** and the **last 25 pages** of the source code for the version you register.
- If the whole program is **50 pages or fewer**, deposit the entire source and say so.
- You may **black out trade-secret portions** as long as the redacted part stays under half and the
  visible code still shows meaningful copyrightable expression.
- Include the page bearing any copyright notice.

## Application fields
- Work: computer program - "Ivy Wolf Art".
- Author: the developer (or the owner entity as work-made-for-hire). If a contractor wrote it, get a
  signed assignment to the owner.
- Claimant: Wolf Co..

## Fee
- Single electronic registration is roughly $45-65.

## Repeat
- Do this per app as each ships (the next Whisper apps use the same steps).
