# Specimen Checklist (SaaS, use-in-commerce marks)

A specimen proves the mark is used with the service. For SaaS it must be a **real screenshot**
(not a mockup) that shows:

- [ ] the mark shown next to the service,
- [ ] a **Login** (or sign-in) button,
- [ ] a subscription / service context (not a one-time product),
- [ ] the page **URL** and the **date** captured.

Save the screenshot at full resolution. One specimen per class per mark.
