Copyright Filing — Ivy Wolf Art

Software code copyright — for copyright.gov

1. What This Protects

This registers the copyright in the Ivy Wolf Art software — the actual code — so it is protected against copying. It is separate from the trademark, which protects the brand name.

NOTE: File at copyright.gov. Deposit rules follow U.S. Copyright Office Circular 61 (Computer Programs). Paperwork to a standard, not legal advice.

2. What to Deposit

  • The first 25 pages and the last 25 pages of the source code for the version being registered.
  • If the whole program is 50 pages or fewer, deposit the entire source and say so.
  • Trade-secret portions may be blacked out, as long as the redacted part stays under half and visible code still shows meaningful copyrightable expression.
  • Include the page that bears any copyright notice.

3. Application Fields

WARNING: If a contractor wrote any of the code, get a signed assignment to Wolf Co. — otherwise the contractor can own the copyright even though you paid for it.

4. Specimen / Use Checklist (for the related trademark)

A trademark specimen must be a real screenshot (not a mockup) that shows:

  • the mark shown next to the service,
  • a Login (or sign-in) button,
  • a subscription / service context (not a one-time product),
  • the page URL and the date captured.

5. Fee and Repeat

Fee: a single electronic registration is roughly ~$45-65.

Repeat this same process per app as each one ships. That is the per-app copyright half of the model.
